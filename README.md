# Get Cueditory

## Android phones and tablets

[Download the latest Cueditory APK](https://github.com/christophergoding-ship-it/Cueditory-Downloads/releases/latest/download/Cueditory.apk)

1. Open this page on your Android phone or tablet and tap the download link.
2. Open the downloaded APK. If asked, allow your browser to install this app, then tap Install.
3. For future updates, use the same link. Build 4038 and later also show an update notice when a newer build is available and the app is idle.

Requires Android 7.0 or later. No GitHub account is needed. Keep the existing app installed when updating to preserve projects. If installation fails, contact the person who invited you before uninstalling.

[Release notes and previous downloads](https://github.com/christophergoding-ship-it/Cueditory-Downloads/releases)

## iPhone and iPad

Install Apple's [TestFlight](https://apps.apple.com/app/testflight/id899247664), then accept your Cueditory invitation email on your Apple device. If you haven't received an invitation, ask the person who invited you to add your email address to the testing group.

The Android APK does not install on Apple devices.

This repository contains public testing downloads only. Cueditory's source code is private.
